# 📚 Website Gudang

Aplikasi web untuk pengelolaan data barang pada sistem gudang dengan supplir.

---

## 🚀 Deskripsi

Website Gudang merupakan sistem informasi berbasis web yang dirancang untuk membantu proses pengelolaan barang di dalam gudang secara lebih efektif dan terstruktur. Aplikasi ini memungkinkan pengguna untuk melakukan pencatatan, pengelolaan, serta pemantauan stok barang secara real-time.

Dengan adanya sistem ini, proses pencatatan barang yang sebelumnya dilakukan secara manual dapat diminimalisir kesalahannya, serta meningkatkan efisiensi dalam pengelolaan data.

Sistem ini juga terintegrasi dengan data supplier sehingga memudahkan dalam pelacakan asal barang, pengadaan barang, serta pengelolaan hubungan dengan supplier.

---

## 🎯 Tujuan Sistem

Sistem Gudang Barang merupakan aplikasi berbasis web yang digunakan untuk:

- Pendataan barang masuk dan keluar
- Manajemen stok barang
- Pengelolaan kategori barang
- Crud barang dan kategori
- Detail barang masuk dan barang keluar
- Menggelolah supplir
- Monitoring aktivitas gudang

---

## 🛠️ Teknologi

- Frontend : React JS (Vite)
- Backend : CodeIgniter 4
- Database : MySQL
- Docker : Docker & Docker Compose
